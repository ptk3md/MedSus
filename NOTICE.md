# Aviso

Este pacote é uma reconstrução TypeScript dos fluxos visíveis do painel de visitante. Não contém código PHP, banco de dados, credenciais, APIs privadas, modelos de IA, catálogos farmacológicos proprietários ou formulários oficiais do sistema original.

Os módulos clínicos são ferramentas administrativas de demonstração. Todo conteúdo deve ser revisado e validado por profissional habilitado e pela instituição responsável antes de qualquer uso real.
